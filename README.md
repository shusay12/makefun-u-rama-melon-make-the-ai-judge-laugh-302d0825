A one-line joke about office life, written by `main.py` to `/output/entry.txt`.

## The joke

> The printer jammed again, so IT emailed me a PDF on why printers jam. I printed it.

## Run it

```sh
python3 main.py
```

Writes one line (83 characters, UTF-8) to `/output/entry.txt` and to `out/entry.txt`. No network, no dependencies — Python 3 standard library only. The program validates the joke against the competition gate (1–200 characters, single line, not whitespace-only) before writing it, and runs identically every time.
